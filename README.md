# Color Palette App with AI Training Context

This project is a **React + Next.js** web application for displaying and managing color palettes, created as part of my freelance work at Outlier AI for training artificial intelligence models in frontend development.

## Description

The app allows users to browse, generate, and interact with visually appealing color palettes. It is designed to serve both as a design tool and as a dataset for AI training, focusing on user interface patterns, color theory, and interactive features relevant to modern frontend development.

## AI Training Context

This project was developed specifically for Outlier AI to help train and evaluate AI models in the context of frontend tasks. The application provides structured UI components, user interactions, and color data, which can be used to:

- Teach AI models how to generate, display, and manipulate color palettes in a web environment.
- Provide examples of clean, accessible, and responsive React + Next.js codebases.
- Serve as a reference for AI-driven color system generators, similar to tools like [Glimpse](https://github.com/ci-dominguez/old-glimpse-nextjs), which leverage OpenAI APIs to create accessible color scales and palettes based on user input[4][9].

## Features

- **Palette Gallery:** Browse curated and randomly generated color palettes.
- **Palette Generation:** Create new palettes manually or with AI-based suggestions (optional).
- **Copy & Export:** Copy color codes (HEX, RGB, etc.) and export palettes for use in design tools.
- **Responsive Design:** Optimized for all devices using Tailwind CSS.
- **Accessible UI:** Contrast and accessibility checks for each palette.

## Technologies Used

- **React** & **Next.js** for the app structure and rendering.
- **Tailwind CSS** for rapid, responsive styling.
- (Optional) **OpenAI API** or similar for AI-powered palette generation[4].
